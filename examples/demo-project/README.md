# Demo project: TourBuddy

A fictional booking app used to demo and test `mcp-project-context`.
All names, contacts and credentials in this folder are **fake test data**. Some are deliberately
secret-looking so the redaction can be tested. None of them are real.

If GitHub push protection flags one of these fixtures when you push, pick
"It's used in tests" in the dialog. The values are invalid by design.
